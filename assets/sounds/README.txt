Taruh file nada alarm bernama "alarm.mp3" di folder ini.

Contoh sumber suara gratis (bebas pakai): freesound.org, pixabay.com/sound-effects.

Kalau file ini belum ada, aplikasi tetap jalan normal — alarmnya cuma
"silent" (layar tetap muncul, tapi tanpa suara). Begitu kamu tambahkan
alarm.mp3 di sini, suara langsung aktif tanpa mengubah kode.
